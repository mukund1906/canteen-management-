CANTEEN CONNECT - MENU PHOTOS
=============================

Is folder (images) mein menu ki asli photos daalein. Site unhe apne aap menu mein laga deti hai.

HOW IT WORKS
- Photo ka naam bilkul neeche likhe naam jaisa hona chahiye (chhote akshar, - ke saath), jaise samosa.jpg.
- .jpg, .png, .webp ya .jpeg chalega.
- Jis item ki photo nahi hogi, uski drawn picture dikhti rahegi.

HOW TO UPLOAD (GitHub par)
1. Repo mein images folder kholein.
2. Add file > Upload files dabayein.
3. Photos drag karke daalein (ek saath kitni bhi) aur Commit changes dabayein.
4. 1-2 minute baad site refresh karein (Ctrl+Shift+R).

TIPS
- Photo ki chaudai lagbhag 600 pixel rakhein aur size 150 KB se kam, taaki menu tez khule.
- Apne canteen ke khane ki khud ki photo sabse achhi rehti hai. Internet se photo lein to free-licence wali lein (Pexels, Unsplash, Wikimedia Commons).
- Kisi website se copyrighted photo copy na karein.
- Owner login ke baad Menu tab mein har item par "Photo" dabake bhi photo laga sakte hain.
